PulseNote Deck Windows v7.5.8 | PN12 + PN15 LEFT + PN15 RIGHT
============================================================
설치: 설치/PulseNoteDeck_v7.5.8_Setup.exe
소스: 소스/app 및 소스/installer (Go)
펌웨어: 펌웨어/PN12, 펌웨어/PN15_LEFT, 펌웨어/PN15_RIGHT

[설정 편집: USB 연결이 필요하지 않습니다]
버튼 설정 화면 상단의 PN12 / 15 왼손 / 15 오른손 탭을 선택합니다.
세 장치의 모든 42개 키를 각각 미리 설정하고, 자동 저장합니다.
장치를 연결·해제하거나 실제 키를 누르더라도 현재 편집 탭은 그대로 유지됩니다.
장치별 입력 이벤트는 실제 펌웨어 모델 ID에 맞는 프로필을 사용합니다.

[화면 개선]
Windows PN15 15키 화면의 키캡 크기 86→100 (디자인 좌표) 확대.
PN12 12키 화면의 키캡 크기 104→114 확대.
두 손 방향의 PN15 대각선 배열과 아이콘·키 이름 유지.
창 크기에 따른 전체 프로그램 확대/축소 동작은 기존 방식 유지.

[연결]
지원: PN12(12키) + PN15 LEFT(15키) + PN15 RIGHT(15키), 최대 3대.
PN12 PND:INFO:12:C3
RIGHT PND:INFO:15:R:C3
LEFT PND:INFO:15:L:C3
기존 PN15 PND:INFO:15:C3는 RIGHT로 인식.
중복 장치 모델은 기존 정책대로 차단합니다.

[검증 범위]
Go 단위 테스트와 go vet 완료; Windows amd64 앱/설치기 빌드 완료.
미검증: Windows GUI 실물 실행, 3개 실물 장치 동시 연결.
설치 전 기존 설정 백업 권장.
