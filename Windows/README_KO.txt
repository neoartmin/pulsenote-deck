PulseNote Deck Windows v7.5.12 | PN12 + PN15 LEFT + PN15 RIGHT
============================================================
설치: 설치/PulseNoteDeck_v7.5.12_Setup.exe
소스: 소스/app 및 소스/installer (Go)
펌웨어: 펌웨어/PN12, 펌웨어/PN15_LEFT, 펌웨어/PN15_RIGHT

[설정 편집: USB 연결이 필요하지 않습니다]
버튼 설정 화면 상단의 PN12 / 15 왼손 / 15 오른손 탭을 선택합니다.
세 장치의 모든 42개 키를 각각 미리 설정하고, 자동 저장합니다.
장치를 연결·해제하거나 실제 키를 누르더라도 현재 편집 탭은 그대로 유지됩니다.
장치별 입력 이벤트는 실제 펌웨어 모델 ID에 맞는 프로필을 사용합니다.

[화면 개선]
Windows PN15 15키 화면의 키캡 크기 86→100 (디자인 좌표) 확대.
PN12 12키 화면의 키캡 크기 104→114 확대.
두 손 방향의 PN15 대각선 배열과 아이콘·키 이름 유지.
창 크기에 따른 전체 프로그램 확대/축소 동작은 기존 방식 유지.

[연결]
지원: PN12(12키) + PN15 LEFT(15키) + PN15 RIGHT(15키), 최대 3대.
PN12 PND:INFO:12:C3
RIGHT PND:INFO:15:R:C3
LEFT PND:INFO:15:L:C3
기존 PN15 PND:INFO:15:C3는 RIGHT로 인식.
중복 장치 모델은 기존 정책대로 차단합니다.

[검증 범위]
Go 단위 테스트와 go vet 완료; Windows amd64 앱/설치기 빌드 완료.
미검증: Windows GUI 실물 실행, 3개 실물 장치 동시 연결.
설치 전 기존 설정 백업 권장.

[텍스트 매크로 - v7.5.12]
기능 목록에서 '텍스트 입력'을 선택하고 버튼 이름과 문구를 입력하세요.
USB 장치가 없어도 PN12 / PN15 LEFT / PN15 RIGHT의 모든 키를 사전 설정할 수 있습니다.
키를 누르면 포커스된 일반 입력창에 UTF-16 유니코드 텍스트를 입력합니다.
한글, 영문, 이모지를 지원하며 전용 다중 행 편집기에서 Enter로 줄바꿈할 수 있습니다.
기존 매크로의 \\n 방식도 계속 지원합니다.
클립보드는 변경하지 않습니다. 관리자 권한으로 실행한 앱, 일부 게임 및 입력창에서는 지원되지 않을 수 있습니다.
민감한 비밀번호나 비밀 키는 평문 설정 파일에 저장하지 마세요.

[Windows 텍스트 입력 수정 - v7.5.12]
Windows x64 SendInput의 INPUT 구조체 크기를 정확한 40바이트로 수정했습니다.
이전 v7.5.9 버전에서 발생하던 오류 87 (The parameter is incorrect)를 수정합니다.
텍스트 매크로 아이콘은 키보드 대신 파란색 T+문장 심벌로 변경했습니다.
기존 키 설정/프로필과 PN12, PN15 LEFT/RIGHT 펌웨어는 유지합니다.
관리자 권한으로 실행한 프로그램과 일부 게임에서는 Windows 입력 보안 정책에 따라 동작하지 않을 수 있습니다.

[텍스트 입력 줄바꿈 개선 - v7.5.12]
Enter로 직접 줄바꿈하고 여러 줄 텍스트를 붙여 넣을 수 있습니다.
PN12와 PN15 LEFT/RIGHT 키별 설정과 기존 기능은 유지됩니다.

[채팅창 줄바꿈 전송 수정 - v7.5.12]
이전 버전은 편집창에서 줄바꿈을 저장했어도 채팅창에서 줄바꿈이 사라질 수 있었습니다.
이제 매크로 문장의 줄바꿈은 유니코드 CR 문자 대신 Shift+Enter 키 입력으로 전송합니다.
메시지를 자동 전송하지 않으며 기존 텍스트/단축키/프로그램/웹사이트/폴더 동작과 설정을 유지합니다.
채팅 프로그램별 줄바꿈 키 조합이 다르면 해당 앱에서는 별도 검증이 필요합니다.
