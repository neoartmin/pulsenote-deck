인성과 층간 접착력이 좋아 반복적인 키 누름과 조립 중 충격에 대응하기 유리하며, PLA보다 일반적으로 열에 대한 여유가 있습니다. 낮은 수축·뒤틀림과 비교적 쉬운 출력은 소량 제작 및 설계 수정의 비용을 줄입니다.

단, 일반 PETG를 난연·방화 소재로 간주하면 안 됩니다. 열원·납땜 인두와 직접 접촉시키지 마세요.PETG 소재 특성 확인 ↗

절연과 단락 방지가 우선

ESP32-C3 보드, 스위치 단자, 납땜부가 서로 접촉하지 않도록 절연 슬리브·열수축튜브를 적용하고, 하우징 내부의 날카로운 모서리와 배선 눌림을 점검합니다. USB 전원 연결 전에 멀티미터로 전원·접지 단락과 매트릭스 배선을 확인합니다.

절연 조치는 저가형 설계에서도 생략할 수 없는 필수 안전 공정입니다.

단심 구리선 수배선

형태를 유지하는 단심 구리선으로 행·열 배선을 정렬하면 소량 제작에서 추가 PCB 제작 비용을 줄이고 결선 상태를 눈으로 점검하기 쉽습니다. 선로는 짧고 단정하게 배치하고 접점 고정과 절연을 우선합니다.

단심 구리선 자체가 전기적 노이즈를 줄인다는 근거는 없습니다. 장거리·유동 배선은 피복 연선과 스트레인 릴리프가 더 적합할 수 있습니다.

설계 원칙: 필요한 만큼만 비용을 사용하고, 신뢰성은 절약하지 않는다. 배선 안정성은 접점 품질·배선 경로·디바운싱·접지 구성에 달려 있으며, 정량적 노이즈 개선 효과는 측정되지 않았습니다.

04 / WHY PULSENOTE EXISTS

반복되는 작업의 흐름을
사용자의 손에 맞추다.

설계 프로그램, 3D 프린팅, 문서 작업과 웹 서비스를 넘나드는 작업 환경에서 ‘기능을 찾는 시간’을 줄이고, 자신에게 맞는 제어 방식을 만드는 것이 PN15 제작의 출발점입니다.

PULSENOTE / BRAND PHILOSOPHY

신호를 만들고,
그 과정을 기록합니다.

Pulse — 전기·전자에서 순간적으로 나타나는 신호
Note — 만들어 온 과정과 결과를 기록하는 노트

PulseNote는 전기·전자에서 순간적으로 나타나는 신호인 ‘Pulse’와, 제가 만들어 온 과정과 결과를 기록한다는 의미의 ‘Note’를 합친 이름입니다.

처음부터 거창한 장비나 완성된 기술이 있었던 것은 아닙니다. 수년간 3D 프린터를 직접 사용하고 손보며 출력 오차를 측정하고, 치수를 보정하고, 부품을 다시 설계하는 일을 반복해 왔습니다. CAD에서 맞았던 치수가 실제 출력물에서는 달라지는 이유를 찾아가며 공차, 압입, 유격, 마찰, 백래시 같은 문제를 하나씩 경험으로 익혔습니다.

그 과정에서 관심은 단순한 출력물을 넘어 실제로 움직이는 기계를 만드는 방향으로 이어졌습니다. 기구를 설계하고, 감속기를 만들고, 모터를 구동하고, 회로와 센서를 연결하고, 직접 작성한 코드로 제어하면서 지금은 3D 프린팅 기반의 유성기어 감속기, 로봇팔, 센서 시스템과 다양한 전자기계 장치를 제작하고 있습니다.

현재는 전자공학을 공부하며 그동안 경험으로 해결해 왔던 문제들을 회로, 센서, 제어의 관점에서 다시 이해하고 다음 설계에 반영하고 있습니다.

PulseNote에는 완성품만 올리지 않습니다. 아이디어가 설계가 되고, 출력과 조립, 배선과 프로그래밍, 실패와 수정의 과정을 거쳐 실제 기계가 움직이기까지의 흐름을 기록합니다.

수년간의 시행착오가 지금의 제작 경험이 되었듯, PulseNote는 제가 무엇을 만들었는지만이 아니라 어떻게 여기까지 왔는지를 계속 남기는 제작 노트입니다.

THE IDEA BEHIND PULSENOTE

매일 누르는 수많은 명령을,
내가 정한 15개의 위치에.

작업을 진행하다 보면 프로그램을 열고, 파일을 찾고, 복사하고, 저장하고, 창을 정렬하는 동작이 반복됩니다. 그 동작들은 어려운 일이 아니라서 오히려 쉽게 지나칩니다. PulseNote는 이 반복을 ‘하나씩 줄일 수 있는 설계 문제’로 바라보았습니다.

원하는 기능을 바로 호출할 수 있도록 물리 키를 배치하되, 하우징부터 펌웨어와 Windows 프로그램까지 직접 설계하면 사용자는 기성 장비의 정해진 사용 방식에 자신을 맞추지 않아도 됩니다. 단순히 버튼 수를 늘리는 대신, 실제로 필요한 기능만 가까이에 두는 방식입니다.

THREE DESIGN OBJECTIVES

기능을 추가하기 전에, 해결하려는 문제부터 정했습니다.

01 / LESS FRICTION

단축키를 찾는 과정까지 단축

반복적인 프로그램 실행, 저장, 웹사이트 호출을 물리 키에 배정합니다. 메뉴와 작업 표시줄을 오가는 대신, 자주 쓰는 명령을 손이 기억하는 위치에서 실행하도록 설계했습니다. 목표는 속도 경쟁이 아니라 끊김 없는 작업 흐름입니다.

02 / USER-DEFINED DESIGN

입력 장치도 작업에 맞게 설계

경사진 하우징, 15키 배열, 각인 키캡, 스위치 장착부를 직접 결정했습니다. 실제 책상 배치와 프로그램별 사용 패턴을 바탕으로 형태와 기능을 함께 조정할 수 있는 입력 도구를 만들고자 했습니다.

03 / TOTAL CONTROL

하드웨어부터 앱까지 한 프로젝트

ESP32-C3의 키 스캔·USB 통신과 Windows 앱의 기능 매핑을 분리해 설계했습니다. 물리 구조를 유지한 채 기능을 확장하고, 필요한 기능이 생길 때 소프트웨어를 개선할 수 있도록 구현했습니다.

FROM DESIGN TO DAILY USE

직접 사용하고, 직접 바꾸는 과정에서 발전합니다.

기계식 스위치와 3D 프린팅 부품을 결합하는 것으로 끝내지 않고, 키캡에 실제 기능을 표기하고 프로그램의 화면 배열을 정리하며 연결과 설정 과정을 반복해서 다듬어 왔습니다. 하드웨어의 배치를 바꾸는 일과 소프트웨어의 기능을 추가하는 일이 같은 설계 목표를 향하도록 구성했습니다.

일상에서 계속 사용할 수 있는 도구라면 보이는 완성도뿐 아니라 조립성, 수정 가능성, 유지보수까지 중요합니다. PulseNote는 사용자에게 익숙한 표준 부품을 선택하고, 제품을 분해하고 수정할 수 있는 구조를 유지하며 발전해 왔습니다.

설정은 간단하게,
활용은 폭넓게.

MODEL IDENTIFICATION

RIGHT · 오른손형 장치 인식LEFT · 왼손형 장치 인식KEY EVENT · 15개 키 입력 전달

Windows 설치 파일과 펌웨어 업로드는 별도 과정입니다. 펌웨어를 처음 설치하는 경우 하드웨어의 손 방향에 맞는 `.ino`를 Arduino IDE에서 선택해 ESP32-C3에 업로드합니다.

06 / ASSEMBLY PROCESS

설계한 구조가
실제 제품으로 완성되는 과정.

하우징, 기계식 스위치, ESP32-C3, 배선과 키캡을 순서대로 결합합니다. 부품을 조립한 뒤에는 펌웨어와 Windows 앱을 연결해 15개 입력을 하나씩 확인합니다.

REAL PRODUCT / ASSEMBLED
  1. 하우징 준비와 부품 적합성 확인3D 프린팅 상판의 스위치 개구부(약 14mm)와 1.50mm 장착 두께를 기준으로 스위치 장착 위치를 확인합니다. 상·하판 결합부와 USB-C 접근부의 형상을 점검합니다.
  2. 기계식 스위치 15개 장착각 스위치를 정해진 배열의 상판 개구부에 넣습니다. 키캡이 결합된 후에도 입력이 자연스럽게 이루어지도록 스위치 높이와 방향을 일정하게 유지합니다.
  3. ESP32-C3 및 3×5 키 매트릭스 구성키 스위치를 행 3개와 열 5개에 연결하는 매트릭스를 구성합니다. 배선은 기준 펌웨어와 일치하도록 정리합니다.
  4. USB 연결·펌웨어 업로드Arduino IDE에서 ESP32C3 Dev Module 및 USB CDC On Boot를 선택한 다음 PN15 RIGHT 또는 LEFT 스케치를 업로드합니다. USB 연결 후 앱에서 장치 인식을 확인합니다.
  5. EPDM 바닥 패드 부착하우징 바닥을 깨끗하게 닦은 뒤 폭 20mm·두께 3mm EPDM 패드를 필요한 길이로 잘라 부착합니다. 패드가 나사 체결부나 USB 케이블 경로를 가리지 않게 배치합니다.
  6. 입력 검사와 키캡 완성키 번호 01~15가 각각 올바르게 전달되는지 확인하고 Windows 프로그램에서 할당 기능을 테스트합니다. 기능명이 표기된 빨강·회색 키캡을 결합하고 최종적으로 상·하판을 조립합니다.
DESIGNED FOR SERVICE

완성 이후에도 접근할 수 있는 구조

분리형 하우징은 내부 컨트롤러와 배선, 스위치 장착부를 확인할 수 있도록 설계됐습니다. 개인 제작자는 키캡 구성을 변경하거나 부품을 점검하고, 필요에 따라 새로운 케이스 형상으로 발전시킬 수 있습니다. 3D 프린팅 기반 제작 방식은 형상 수정 후 재출력하는 과정을 비교적 유연하게 지원합니다.

정확한 배선 작업은 공개된 기준 펌웨어의 GPIO 정의와 실제 사용한 보드 핀 표시를 함께 확인해 진행합니다. 제품의 단위별 구성과 부품의 기능은 ‘사용 부품’에서 자세히 안내합니다.

MODULAR BY DESIGN

표준 부품과 맞춤형 설계의 조화

PN15는 쉽게 구할 수 있는 ESP32-C3 계열 보드와 MX 계열 스위치 장착 형상을 중심으로 구성했습니다. 하우징은 3D 프린팅으로 제작해 부품에 맞춘 형상을 반복 수정할 수 있고, 키의 기능은 PC 소프트웨어에서 변경하도록 분리했습니다.

따라서 물리 부품, 입력 펌웨어, 실행 기능을 각각 관리하면서도 하나의 제품으로 연동할 수 있습니다. 이는 직접 만드는 제품이면서도 일상에서 실제로 사용하는 도구를 목표로 한 설계 선택입니다.

PulseNote 프로젝트 이용 안내

프로젝트에 공개된 자체 제작 하드웨어 설계, 소프트웨어, 펌웨어, 문서 및 이미지는 개인 학습, 연구, 비상업적 참고를 목적으로 공개합니다. PulseNote의 별도 승인이 없는 제3자의 상업적 제조·판매·유통·재브랜딩 및 상업적 재배포를 허용하지 않는다는 프로젝트 방침을 안내합니다.

실제 법적 적용 범위는 각 배포 파일의 개별 라이선스와 저작권 표시를 확인해야 하며, 외부 라이브러리·부품 등 제3자 권리는 별도입니다. 이 문구 자체가 별도의 라이선스 파일을 대체하지는 않습니다.
