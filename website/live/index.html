THE REAL VALUE IS CONFIGURABILITY

15개 키, 하나로 정해지지 않는 사용법.

PN15가 전송하는 것은 ‘어떤 키가 눌렸는가’라는 입력 이벤트입니다. 실제로 실행할 프로그램, URL, 단축키, 텍스트 매크로와 창 제어 등의 기능은 Windows 프로그램에서 관리합니다. 따라서 같은 키라도 프로필을 바꾸면 설계 작업용 버튼, 문서 작업용 버튼, 미디어 제어용 버튼으로 역할을 변경할 수 있습니다.

PN12, PN15 LEFT, PN15 RIGHT의 키 구성을 장치가 연결되지 않은 상태에서도 미리 설정할 수 있으며, 연결된 모델의 식별 문자열에 맞는 프로필로 입력을 처리합니다. 한 컴퓨터에서 여러 작업 흐름을 사용하는 사람을 고려한 구조입니다.

PLATFORM EXTENSION

Windows를 중심으로, Android까지 확장한 프로젝트.

PulseNote 프로젝트는 Windows 제어 프로그램과 Android 앱을 별도로 개발해 왔습니다. 두 플랫폼은 같은 PN12·PN15 기준 펌웨어를 사용하며, 장치 모델과 키 번호를 식별하는 통신 구조를 공유합니다. 사용 환경별 인터페이스와 제공 기능은 각 플랫폼의 특성에 맞춰 구현합니다.

Windows 프로그램은 설치형 실행 파일로 제공하고, 펌웨어는 ESP32-C3에 업로드하는 Arduino 스케치로 구분해 배포합니다. 소프트웨어 업데이트와 물리 하드웨어의 교체를 분리할 수 있다는 점도 자체 개발 구조의 장점입니다.

반복되는 작업의 흐름을
사용자의 손에 맞추다.

설계 프로그램, 3D 프린팅, 문서 작업과 웹 서비스를 넘나드는 작업 환경에서 ‘기능을 찾는 시간’을 줄이고, 자신에게 맞는 제어 방식을 만드는 것이 PN15 제작의 출발점입니다.

THE IDEA BEHIND PULSENOTE

매일 누르는 수많은 명령을,
내가 정한 15개의 위치에.

작업을 진행하다 보면 프로그램을 열고, 파일을 찾고, 복사하고, 저장하고, 창을 정렬하는 동작이 반복됩니다. 그 동작들은 어려운 일이 아니라서 오히려 쉽게 지나칩니다. PulseNote는 이 반복을 ‘하나씩 줄일 수 있는 설계 문제’로 바라보았습니다.

원하는 기능을 바로 호출할 수 있도록 물리 키를 배치하되, 하우징부터 펌웨어와 Windows 프로그램까지 직접 설계하면 사용자는 기성 장비의 정해진 사용 방식에 자신을 맞추지 않아도 됩니다. 단순히 버튼 수를 늘리는 대신, 실제로 필요한 기능만 가까이에 두는 방식입니다.

THREE DESIGN OBJECTIVES

기능을 추가하기 전에, 해결하려는 문제부터 정했습니다.

01 / LESS FRICTION

단축키를 찾는 과정까지 단축

반복적인 프로그램 실행, 저장, 웹사이트 호출을 물리 키에 배정합니다. 메뉴와 작업 표시줄을 오가는 대신, 자주 쓰는 명령을 손이 기억하는 위치에서 실행하도록 설계했습니다. 목표는 속도 경쟁이 아니라 끊김 없는 작업 흐름입니다.

02 / USER-DEFINED DESIGN

입력 장치도 작업에 맞게 설계

경사진 하우징, 15키 배열, 각인 키캡, 스위치 장착부를 직접 결정했습니다. 실제 책상 배치와 프로그램별 사용 패턴을 바탕으로 형태와 기능을 함께 조정할 수 있는 입력 도구를 만들고자 했습니다.

03 / TOTAL CONTROL

하드웨어부터 앱까지 한 프로젝트

ESP32-C3의 키 스캔·USB 통신과 Windows 앱의 기능 매핑을 분리해 설계했습니다. 물리 구조를 유지한 채 기능을 확장하고, 필요한 기능이 생길 때 소프트웨어를 개선할 수 있도록 구현했습니다.

FROM DESIGN TO DAILY USE

직접 사용하고, 직접 바꾸는 과정에서 발전합니다.

기계식 스위치와 3D 프린팅 부품을 결합하는 것으로 끝내지 않고, 키캡에 실제 기능을 표기하고 프로그램의 화면 배열을 정리하며 연결과 설정 과정을 반복해서 다듬어 왔습니다. 하드웨어의 배치를 바꾸는 일과 소프트웨어의 기능을 추가하는 일이 같은 설계 목표를 향하도록 구성했습니다.

일상에서 계속 사용할 수 있는 도구라면 보이는 완성도뿐 아니라 조립성, 수정 가능성, 유지보수까지 중요합니다. PulseNote는 사용자에게 익숙한 표준 부품을 선택하고, 제품을 분해하고 수정할 수 있는 구조를 유지하며 발전해 왔습니다.

05 / HOW TO USE

설정은 간단하게,
활용은 폭넓게.

USB로 연결하고 원하는 키에 기능을 지정하면 됩니다. 기본 입력과 작업 실행의 역할을 분리했기 때문에 장치를 연결하기 전에도 키 구성을 준비하고, 필요할 때 프로필을 변경할 수 있습니다.

01

Windows 앱 설치

공식 Windows 설치 프로그램을 실행하고 PulseNote Deck Control Center를 준비합니다. 기존 설정을 사용 중이라면 설치 전에 백업하는 방식으로 관리할 수 있습니다.

02

PN15 연결

USB-C 케이블로 PC에 연결하면 ESP32-C3 펌웨어가 USB CDC 시리얼 장치로 인식됩니다. 프로그램에서 장치와 COM 포트를 확인합니다.

03

키와 프로필 구성

PN15 RIGHT/LEFT 탭을 선택하고 15개 버튼의 기능·이름·색상과 프로필을 지정합니다. 연결되지 않은 장치의 설정도 미리 편집할 수 있습니다.

04

작업 흐름에 적용

기계식 키를 누르면 해당 키의 이벤트가 PC에 전송되고, 저장한 프로필에 따라 프로그램 실행·단축키·검색·미디어 제어 같은 명령이 실행됩니다.

REAL-WORLD EXAMPLES

작업 환경마다 달라지는 15개 키의 역할

아래 구성은 사용 가능한 기능을 활용한 예시로, 사용자가 직접 자신의 프로그램과 작업 방식에 맞춰 설정할 수 있습니다.

DESIGN / CAD

설계·제작 작업

Fusion 실행, Bambu Studio 실행, 작업 폴더 열기, 저장 단축키, 화면 캡처를 한곳에 배치합니다. 모델링에서 출력 준비로 이어지는 작업 전환을 간결하게 만듭니다.

STUDY / DOCUMENTS

학습·문서 작성

문서 저장, 복사·붙여넣기, 자료 검색, 텍스트 문구 입력, 자주 쓰는 링크 열기를 묶습니다. 반복 입력을 줄이고 작성 내용에 집중하도록 도와줍니다.

MEDIA / DESKTOP

일상 PC 제어

재생·일시정지, 볼륨, 다음 곡, 클립보드 기록, 창 정렬, 캡처 도구 호출 등 운영체제 기능을 키보드 옆 보조 입력 장치에서 바로 제어합니다.

MODEL IDENTIFICATION

하드웨어 방향을 구별하는 펌웨어 식별

PN15의 오른손형과 왼손형은 물리 키의 번호 체계를 공유하지만 서로 다른 장치 식별 문자열을 제공합니다. Windows 앱은 입력 이벤트를 모델별 설정과 연결해 표시할 키 배열과 동작 프로필을 선택합니다.

RIGHT · 오른손형 장치 인식LEFT · 왼손형 장치 인식KEY EVENT · 15개 키 입력 전달

Windows 설치 파일과 펌웨어 업로드는 별도 과정입니다. 펌웨어를 처음 설치하는 경우 하드웨어의 손 방향에 맞는 `.ino`를 Arduino IDE에서 선택해 ESP32-C3에 업로드합니다.

DESIGNED FOR SERVICE

완성 이후에도 접근할 수 있는 구조

분리형 하우징은 내부 컨트롤러와 배선, 스위치 장착부를 확인할 수 있도록 설계됐습니다. 개인 제작자는 키캡 구성을 변경하거나 부품을 점검하고, 필요에 따라 새로운 케이스 형상으로 발전시킬 수 있습니다. 3D 프린팅 기반 제작 방식은 형상 수정 후 재출력하는 과정을 비교적 유연하게 지원합니다.

정확한 배선 작업은 공개된 기준 펌웨어의 GPIO 정의와 실제 사용한 보드 핀 표시를 함께 확인해 진행합니다. 제품의 단위별 구성과 부품의 기능은 ‘사용 부품’에서 자세히 안내합니다.

MODULAR BY DESIGN

표준 부품과 맞춤형 설계의 조화

PN15는 쉽게 구할 수 있는 ESP32-C3 계열 보드와 MX 계열 스위치 장착 형상을 중심으로 구성했습니다. 하우징은 3D 프린팅으로 제작해 부품에 맞춘 형상을 반복 수정할 수 있고, 키의 기능은 PC 소프트웨어에서 변경하도록 분리했습니다.

따라서 물리 부품, 입력 펌웨어, 실행 기능을 각각 관리하면서도 하나의 제품으로 연동할 수 있습니다. 이는 직접 만드는 제품이면서도 일상에서 실제로 사용하는 도구를 목표로 한 설계 선택입니다.

08 / THE PULSENOTE STORY

아이디어에서 완조립 제품까지,
AI와 함께 다듬은 개발 기록.

PulseNote의 개발 과정은 하드웨어 모델링과 3D 프린팅, 입력 펌웨어, Windows 소프트웨어, 기능이 표기된 키캡을 하나의 제품으로 묶어 가는 반복 설계 과정입니다.

FROM CAD MODEL TO PHYSICAL DEVICE
01 / THE IDEA

실제 작업에서 시작된 아이디어

단축키, 프로그램 실행, 웹사이트 호출처럼 매일 반복하는 동작을 한곳에 묶고자 했습니다. 사용 목적을 먼저 정의하고 키 수와 배치, 필요 기능을 구체화했습니다.

02 / MECHANICAL DESIGN

형상을 설계하고 직접 출력하다

키 간격과 상판 경사, USB 포트 접근성, 스위치 장착부와 케이스 분리 구조를 검토했습니다. Fusion 360 기반 모델과 3D 프린팅 결과를 비교하며 실제 손에 닿는 형상을 발전시켰습니다.

03 / ELECTRONICS & FIRMWARE

15개의 스위치에 입력 체계를 부여하다

ESP32-C3의 3×5 입력 매트릭스와 USB CDC 통신을 구현했습니다. 오른손형·왼손형의 장치 식별을 구분하면서 공통된 입력 처리 구조를 유지하도록 구성했습니다.

04 / SOFTWARE EVOLUTION

하드웨어를 실제 작업 도구로 확장하다

Windows 제어 프로그램에서 버튼 설정, 장치 인식, 프로필 관리와 다양한 매크로 기능을 발전시켰습니다. 사용 시나리오를 고려해 기능 선택과 화면 구성을 반복적으로 정리했습니다.

05 / AI-ASSISTED DEVELOPMENT

AI를 활용해 검토하고 개선하다

아이디어의 정리, 설계 대안 비교, 코드 검토, UI 개선과 문서 작성 과정에서 AI를 협업 도구로 활용했습니다. 실제 설계 선택과 구현, 시험은 제작자가 중심이 되어 결정했습니다.

06 / FINISHED PN15

하나의 완성품으로 연결하다

하우징과 내부 회로를 결합하고 각 키의 역할이 드러나는 빨강·회색 키캡을 완성했습니다. 지금의 PN15는 형태·조작·설정 프로그램이 서로 연결된 개발 결과입니다.
